# Kevro

Keyboard-first window and app control for macOS, written in Rust.

Kevro is a small menu-bar utility that lets you launch or focus apps with one
keypress, snap windows into layouts and move focus between windows by
direction, all configured in one TOML file.

> Status: early development (Phase 1). See [`docs/BRIEF.md`](docs/BRIEF.md) for
> the design brief.
